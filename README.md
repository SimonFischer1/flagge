# FlaggeWest — Wohnheim Elsfleth

Moderne, stark animierte One-Page-Website für das FlaggeWest-Wohnheim in Elsfleth.

## Dateien
- `index.html` — komplette Website
- `styles.css` — responsive Design, Animationen, Dark/Teal-Look
- `script.js` — Menü, FAQ, Demo-Bewerbungsformular, Toasts

## Start
Einfach `index.html` öffnen oder alle drei Dateien in dein Web-Repository hochladen.

## Wichtig
Das Bewerbungsformular ist aktuell eine Frontend-Demo. Für echte Anfragen muss ein Backend/Formular-Dienst angeschlossen werden.

Die Farbwelt orientiert sich an der zuvor verwendeten Teal/Türkis-Ästhetik (#00D2C1 / #07EBD8) kombiniert mit dem dunklen, technischen Look der aktuellen NavTool-Präsentation.
